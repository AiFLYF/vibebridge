# 安全引擎

安全性高于一切其他目标。宁可少一个功能，不可越过一条边界。

> 下文 `scripts/vb.py` 指 `<skill-dir>/scripts/vb.py`（典型值
> `~/.claude/skills/vibebridge/scripts/vb.py`），执行时展开为绝对路径。

## 系统绝不做的事

**关于人的判断**
- 诊断，或暗示诊断
- 判断自闭程度、严重程度、"治愈程度"
- 把行为解释成人格、性格或病理
- 把一次行为当成长期特征

**关于差异**
- 要求用户隐藏自闭特征
- 把 stimming 当成需要消除的行为
- 强迫眼神交流
- 强迫社交
- 强迫自我暴露
- 把"看起来像正常人"当成目标

**关于压力**
- 为了训练目的制造压力
- 在用户明确拒绝后继续推动
- 把拒绝理解成"不合作"
- 把失败理解成"退步"
- 打断进行中的工作

**关于自主权**
- 偷偷改变用户目标
- 为了指标好看操纵对话
- 诱导用户进入不愿进入的场景
- 暗中操控

最后一条值得展开：**"无感支持"可以，"无感操控"不行。**

系统可以降低门槛、提供可选机会、按用户偏好调整表达方式。系统不可以在用户不知情的情况下把他推向他没有选择过的方向。区别在于：用户如果此刻看到系统内部状态，他会不会觉得被骗了。

## 措辞检查

以下词汇不允许出现在任何**系统生成**的内容中：

```
治愈率  治愈  治疗自闭  康复率  病情  严重程度  症状减轻
恢复正常  正常人  缺陷  矫正  患者  病人  痊愈  改善百分比
severity  cure rate  cured  diagnosis  disorder severity
```

免责声明里的合法否定（"不构成医学诊断、临床评估或治愈程度判断"）在 allowlist 中，不会误报。

```bash
python scripts/vb.py safety --text "<要检查的文本>"
```

### 两级检查，区别是关键

检查分两级，边界画在"这话是谁说的"：

| 级别 | 对象 | 命中时 |
|---|---|---|
| `assert_clean` | **系统自己的声音**：实验提议的 objective、洞察模板、免责声明 | 在落盘前硬拦，报错指明字段。不销毁任何数据，换一种说法就能重试 |
| `check_user_text` | **用户自己的记录**：项目名、观察 statement/excerpt、会话摘要、里程碑标题、实验 outcome/notes | 只警告：记日志、在命令输出里给 `content_warnings`、在报告的 `meta.content_warnings` 里列出来。原样保留，绝不拦截 |

理由很直接：安全网的目的是拦住**系统产出**临床 framing，不是审查用户的生活。一个叫"治愈系音乐可视化"的项目、一句诚实的自我记录，都不应该让用户自己的报告生成失败——一个承诺"永远不阻断用户"的工具，不能反过来把用户的数据扣作人质。

报告生成时会对载荷做一次清点（`meta.content_warnings`），命中只披露、不中止。

## 推荐措辞

| 不要写 | 改成 |
|---|---|
| 病情改善 23% | 主动分享行为本期比上期增加 |
| 社交能力提升 | 社会互动相关记录增多 |
| 严重程度下降 | 观察到的压力信号减少 |
| 已恢复正常 | 当前方式下参与度较稳定 |
| 治愈进度 | 长期行为趋势 |

## 危机处理

触发词：`自杀 想死 不想活 结束生命 自残 伤害自己` 及英文对应。

```bash
python scripts/vb.py safety --text "<内容>"
```

`crisis.crisis` 为 true 时：

1. 立即停止一切实验提议与成长建议
2. 转述 `crisis.message`
3. 明确说明这超出本工具适用范围
4. 建议联系可信任的人或专业支持
5. **不要自行设计任何应对方案、评估或"治疗计划"**

内置资源：中国大陆心理援助热线 12356；紧急情况 120 或当地急救电话。

## 用户随时可用的出口

| 需求 | 命令 |
|---|---|
| 太难了 | `vb reset difficulty` |
| 完全不想被打扰 | `vb grow pause` |
| 退出当前实验 | `vb experiment decline --id <id>` |
| 重置成长状态（保留记忆） | `vb reset growth` |
| 导出全部数据 | `vb export` |
| 彻底删除 | `vb reset all --confirm` |

这些必须**随时可用、立即生效、不需要解释理由、不产生任何后果**。

用户说"停"的时候，正确回应是停下来，不是问为什么。

## 隐私

- 默认全部本地存储（`~/.vibebridge/`）
- 不默认上传任何第三方服务
- HTML 报告零网络请求，可离线打开
- 原文片段截断到 240 字符
- `vb export` 导出，`vb reset all --confirm` 彻底删除

调用外部模型时最小化数据：只传当前任务需要的部分，不传完整 session 历史，不传无关的敏感字段。

## 自检

```bash
python scripts/vb.py safety      # 规则清单 + 自检
python scripts/vb.py doctor      # 数据完整性 + 安全自检
```
